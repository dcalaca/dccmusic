CONFIGURAR VARIÁVEIS DE AMBIENTE NO VERCEL

As credenciais de produção NÃO devem ser armazenadas neste repositório.
Configure valores reais somente em Vercel → Project → Settings → Environment Variables.

Variáveis principais:

NEXT_PUBLIC_SUPABASE_URL=<public-url>
NEXT_PUBLIC_SUPABASE_ANON_KEY=<publishable-anon-key>
SUPABASE_SERVICE_ROLE_KEY=<server-only-service-role-key>
NEXTAUTH_URL=https://www.dccmusic.online
NEXTAUTH_SECRET=<server-only-random-secret>
ADMIN_EMAIL=<admin-email>
ADMIN_PASSWORD=<server-only-strong-password>

Regras:
- Nunca commitar senhas, tokens, API keys, service-role keys ou webhook secrets.
- Variáveis secretas devem ser server-only e cadastradas como Sensitive no Vercel.
- Somente valores realmente públicos podem usar o prefixo NEXT_PUBLIC_.
- Após trocar uma credencial, faça um novo deployment para que a produção use o novo valor.
